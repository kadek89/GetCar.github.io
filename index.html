Cara Install Aplikasi

Ikuti 4 langkah mudah berikut untuk memasang aplikasi Get Car Mitra di HP Android kamu:

1
Unduh file APK

Tekan tombol Unduh Aplikasi (APK) di atas, tunggu sampai unduhan selesai. File tersimpan di folder Downloads HP kamu.

2
Buka file APK

Buka aplikasi File Manager / Files → folder Downloads → ketuk file GetCar-Mitra.apk.

3
Izinkan instal dari sumber tidak dikenal

Jika muncul peringatan keamanan, ketuk Settings / Pengaturan → aktifkan "Izinkan dari sumber ini" → kembali → tekan Install.

4
Selesai — buka aplikasinya!

Setelah terpasang, icon GetCar muncul di layar utama. Login dengan akun mitra kamu dan mulai bekerja! 🎉
